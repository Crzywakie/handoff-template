# Multi-Window Handoff Template

A protocol for running long projects with an AI model that forgets
everything between sessions. You write a structured handoff document at
the end of each context window; the next window starts by reading it.
Nothing survives the gap except what is written down.

This template was developed and refined across roughly seven months and
hundreds of working sessions of a single real project, evolving through
use rather than design. Every section exists because a crossing failed
without it.

The full template is in [TEMPLATE.md](TEMPLATE.md). It explains its own
use. A fuller write-up — evidence, method, and operator's guide — is in
progress and will be linked here when complete.
